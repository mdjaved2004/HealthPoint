## 🎨 Customization

### Update Content
Edit the page files in `src/pages/` to update content

### Update Navigation
Edit `src/components/Header.jsx` to modify menu items

### Update Footer
Edit `src/components/Footer.jsx` to update company info

### Update Styling
All original CSS files are imported in `src/App.css`

### Update Assets
Replace images and fonts in `public/assets/`

## 📱 Responsive Design

The app includes Bootstrap and responsive CSS for:
- Desktop (1200px+)
- Tablets (768px - 1199px)
- Mobile (below 768px)

Mobile menu automatically appears on small screens!
