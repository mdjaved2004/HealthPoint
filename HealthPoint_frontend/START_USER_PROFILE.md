## 🔑 HOW IT WORKS

**User Login**
1. User enters credentials
2. AuthContext stores user data
3. Header shows UserProfile dropdown
4. User sees their avatar with initials

**View Profile**
1. Click avatar → dropdown opens
2. Click "My Profile" → navigate to /profile
3. Profile page displays user information

**Edit Profile**
1. On profile page, click "Edit Profile"
2. Form fields become editable
3. Make changes and click "Save"
4. Success message shows
5. Data saved to backend

**Logout**
1. Click avatar → dropdown opens
2. Click "Sign Out" button
3. User logged out securely
4. Redirect to home page
